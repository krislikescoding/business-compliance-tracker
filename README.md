# Data Act 2025 (DUAA) Compliance Checker

## Project Overview
I built this interactive web application to help UK small businesses evaluate and audit their data handling practices. The goal is to give business owners a practical tool to check their workflows prior to the implementation of the new laws on 19 June 2026.

## Why I Built This
With the upcoming Data (Use and Access) Act 2025 changing the landscape for data management, I wanted to create a solution that helps businesses stay ahead of legal deadlines. By launching this tool early, it gives users the necessary lead time to understand the updated guidelines and adapt their practices safely.

## Tech & Skills
* **Frontend Design:** Created a clean, responsive user interface using HTML and CSS.
* **Logic & Evaluation:** Programmed an interactive questionnaire using JavaScript that calculates a business's compliance score instantly. By running the logic directly in the browser, users can safely evaluate their practices without their sensitive data ever leaving their device.
* **Commercial Awareness:** Researched real-world UK data legislation to map out the application's feedback logic.

## Next Steps
The core application is fully deployed and live. I am currently reaching out to business owners and professionals to gather feedback on user experience and real-world utility.
